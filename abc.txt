**Hướng dẫn chi tiết giải đề WPF C# (Patient Information Management)**

### **1. Chuẩn bị project**
1. Mở Visual Studio → **Create a new project** → Chọn **WPF App (.NET Framework)** hoặc **WPF App** (.NET 6/8).
2. Đặt tên project ví dụ: `KTNguyenThiAnh_2019876578` (theo yêu cầu tạo thư mục).
3. Thêm class Model:

```csharp
// Patient.cs
public class Patient
{
    public string Ma { get; set; } = string.Empty;
    public string HoTen { get; set; } = string.Empty;
    public DateTime NgayVaoVien { get; set; }
    public string LoaiBenhNhan { get; set; } = string.Empty; // "Nội trú" hoặc "Ngoại trú"
}
```

```xaml
        </StackPanel>

```

### **3. Câu 1b: Style & Template (Resources)**

Thêm vào `<Window.Resources>`:

```xaml
<Window.Resources>
    <!-- Style cho DataGrid -->
    <Style TargetType="DataGrid">
        <Setter Property="ColumnHeaderHeight" Value="40"/>
        <Setter Property="FontWeight" Value="Bold"/>
        <Setter Property="HorizontalGridLinesBrush" Value="LightGray"/>
        <Setter Property="VerticalGridLinesBrush" Value="LightGray"/>
    </Style>

    <!-- Style cho Button ellipse vàng -->
    <Style x:Key="GoldEllipseButton" TargetType="Button">
        <Setter Property="Background" Value="Gold"/>
        <Setter Property="Foreground" Value="Black"/>
        <Setter Property="FontWeight" Value="Bold"/>
        <Setter Property="Template">
            <Setter.Value>
                <ControlTemplate TargetType="Button">
                    <Ellipse x:Name="ellipse" Fill="{TemplateBinding Background}" Stroke="DarkGoldenrod" StrokeThickness="3"/>
                    <ContentPresenter HorizontalAlignment="Center" VerticalAlignment="Center"/>
                </ControlTemplate>
            </Setter.Value>
        </Setter>
    </Style>
</Window.Resources>
```

Áp dụng style cho 2 button:
```xaml
<Button Style="{StaticResource GoldEllipseButton}" ... />
```

### **4. Code Behind MainWindow.xaml.cs (Câu 2 & Câu 3)**

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Windows;

namespace YourProject
{
    public partial class MainWindow : Window
    {
        private List<Patient> patients = new List<Patient>();

        public MainWindow()
        {
            InitializeComponent();
            dpNgayVao.SelectedDate = DateTime.Today; // Mặc định hôm nay
        }

        private void btnNhap_Click(object sender, RoutedEventArgs e)
        {
            // Câu 3: Validation
            if (string.IsNullOrWhiteSpace(txtMa.Text) ||
                string.IsNullOrWhiteSpace(txtHoTen.Text) ||
                dpNgayVao.SelectedDate == null ||
                cbLoai.SelectedItem == null)
            {
                MessageBox.Show("Tất cả các trường đều phải có dữ liệu!", "Lỗi", MessageBoxButton.OK, MessageBoxImage.Warning);
                return;
            }

            DateTime ngayVao = dpNgayVao.SelectedDate.Value;
            if (ngayVao > DateTime.Today)
            {
                MessageBox.Show("Ngày vào viện phải nhỏ hơn hoặc bằng ngày hiện tại!", "Lỗi", MessageBoxButton.OK, MessageBoxImage.Warning);
                return;
            }

            // Thêm vào danh sách
            var patient = new Patient
            {
                Ma = txtMa.Text.Trim(),
                HoTen = txtHoTen.Text.Trim(),
                NgayVaoVien = ngayVao,
                LoaiBenhNhan = ((ComboBoxItem)cbLoai.SelectedItem).Content.ToString()
            };

            patients.Add(patient);
            dgPatients.ItemsSource = null;           // Refresh
            dgPatients.ItemsSource = patients;

            // Clear form
            txtMa.Clear();
            txtHoTen.Clear();
            cbLoai.SelectedIndex = -1;
            dpNgayVao.SelectedDate = DateTime.Today;

            MessageBox.Show("Nhập dữ liệu thành công!", "Thông báo");
        }

        private void btnChiTiet_Click(object sender, RoutedEventArgs e)
        {
            // Lọc bệnh nhân Nội trú
            var noiTruList = patients.Where(p => p.LoaiBenhNhan == "Nội trú").ToList();

            if (noiTruList.Count == 0)
            {
                MessageBox.Show("Không có bệnh nhân Nội trú nào!", "Thông báo");
                return;
            }

            // Mở cửa sổ chi tiết
            var detailWindow = new DetailWindow(noiTruList);
            detailWindow.ShowDialog();
        }
    }
}
```

### **5. Tạo cửa sổ Chi tiết (DetailWindow.xaml)**

Thêm **Window** mới tên `DetailWindow.xaml`:

```xaml
<Window x:Class="YourProject.DetailWindow"
        Title="Danh sách bệnh nhân Nội trú" Height="500" Width="700">
    <Grid>
        <DataGrid x:Name="dgNoiTru" Margin="10" AutoGenerateColumns="False" IsReadOnly="True">
            <DataGrid.Columns>
                <DataGridTextColumn Header="Mã" Binding="{Binding Ma}"/>
                <DataGridTextColumn Header="Họ tên" Binding="{Binding HoTen}"/>
                <DataGridTextColumn Header="Ngày vào viện" Binding="{Binding NgayVaoVien, StringFormat=dd/MM/yyyy}"/>
            </DataGrid.Columns>
        </DataGrid>
    </Grid>
</Window>
```

**DetailWindow.xaml.cs**:

```csharp
public partial class DetailWindow : Window
{
    public DetailWindow(List<Patient> noiTruList)
    {
        InitializeComponent();
        dgNoiTru.ItemsSource = noiTruList;
    }
}
```

### **6. Lưu ý quan trọng**
- **Ngày vào viện**: Dùng `StringFormat=dd/MM/yyyy` trong Binding.
- **Nút vàng ellipse**: Dùng `Ellipse` trong `ControlTemplate`.
- **Validation**: Kiểm tra rỗng + ngày không được lớn hơn hôm nay.
- **DataGrid**: Bind trực tiếp `List<Patient>`.
- Build và test đầy đủ chức năng trước khi nộp.

Bạn có thể copy-paste code trên và chỉnh sửa tên project/class cho phù hợp. Nếu gặp lỗi cụ thể (ví dụ: binding, style...), paste lỗi vào đây mình hỗ trợ tiếp!
