Dưới đây là hướng dẫn chi tiết để bạn thực hiện bài tập dựa trên nội dung trong ảnh. Tôi giả định các trường nhập là "Mã nhân viên", "Họ tên", "Giới tính", "Số tiền bán hàng" (dựa trên ngữ cảnh "so tien banh hang" trong Câu 2, có thể là lỗi đánh máy từ "Số tiền bán hàng" thay vì "So dien thoai bang hang"). Tiêu đề cửa sổ là "Thông tin nhân viên", nhưng code xử lý như "khách hàng" theo mô tả ở Câu 2 (có thể là lỗi trong đề bài, tôi điều chỉnh để phù hợp).

Bài tập yêu cầu tạo ứng dụng WPF với giao diện, style/template, và code behind cho các nút lệnh. Tôi sẽ cung cấp mã nguồn đầy đủ, bạn có thể copy-paste vào Visual Studio để chạy.

### Bước 1: Tạo project
- Mở Visual Studio, tạo mới WPF App (.NET Framework hoặc .NET Core, tùy phiên bản).
- Đặt tên solution theo yêu cầu: `De3_[3 số cuối mã sinh viên của bạn]` (ví dụ: `De3_412` nếu mã SV của bạn kết thúc bằng 412).
- Code Style và Template đặt trong Window.Resources (như yêu cầu).
- Thêm class mới tên `KhachHang.cs`.

### KhachHang.cs (Class dữ liệu)
```csharp
using System;

namespace De3  // Thay De3 bằng tên namespace của project bạn
{
    public class KhachHang
    {
        public string Ma { get; set; }
        public string HoTen { get; set; }
        public string GioiTinh { get; set; }
        public double SoTienBanHang { get; set; }
        public double HoaHong { get; set; }
    }
}
```

### MainWindow.xaml (Giao diện chính, Câu 1 a và b)
Sử dụng Grid để sắp xếp. Áp dụng Style cho TextBox (font size 15, chữ green, nền pink). Tôi thêm 3 Label với style màu như trong sơ đồ (DarkOrange font 35 bold, LimeGreen, LightSteelBlue). Giả định không cần Template phức tạp vì đề nói "Style (và/học) Template", tôi dùng Style đơn giản.

### MainWindow.xaml.cs (Code behind cho MainWindow, Câu 2 a và b)
```csharp
using System.Collections.ObjectModel;
using System.Windows;
using System;

namespace De3
{
    public partial class MainWindow : Window
    {
        public ObservableCollection<KhachHang> ListKhachHang { get; set; } = new ObservableCollection<KhachHang>();

        public MainWindow()
        {
            InitializeComponent();
            dgKhachHang.ItemsSource = ListKhachHang;
        }

        // Câu 2 a: Nút Thêm - Thêm vào DataGrid, tính hoa hồng = 10% * số tiền bán hàng (giả định - là lỗi đánh máy, nên dùng +)
        private void btnThem_Click(object sender, RoutedEventArgs e)
        {
            if (string.IsNullOrEmpty(txtMa.Text) || string.IsNullOrEmpty(txtHoTen.Text) || string.IsNullOrEmpty(txtSoTien.Text))
            {
                MessageBox.Show("Vui lòng nhập đầy đủ thông tin!");
                return;
            }

            double soTien;
            if (!double.TryParse(txtSoTien.Text, out soTien))
            {
                MessageBox.Show("Số tiền bán hàng phải là số!");
                return;
            }

            string gioiTinh = rbNam.IsChecked == true ? "Nam" : (rbNu.IsChecked == true ? "Nu" : "");
            if (string.IsNullOrEmpty(gioiTinh))
            {
                MessageBox.Show("Vui lòng chọn giới tính!");
                return;
            }

            var kh = new KhachHang
            {
                Ma = txtMa.Text,
                HoTen = txtHoTen.Text,
                GioiTinh = gioiTinh,
                SoTienBanHang = soTien,
                HoaHong = soTien * 0.1  // 10% * số tiền
            };

            ListKhachHang.Add(kh);

            // Xóa form sau khi thêm
            txtMa.Text = "";
            txtHoTen.Text = "";
            txtSoTien.Text = "";
            rbNam.IsChecked = false;
            rbNu.IsChecked = false;
        }

        // Câu 2 b: Nút Window 2 - Mở Window2 (hiển thị khác, giả định hiển thị danh sách ở Window2)
        private void btnWindow2_Click(object sender, RoutedEventArgs e)
        {
            Window2 w2 = new Window2(this);
            w2.Show();
        }
    }
}
```

### Window2.xaml.cs (Code behind cho Window2, Câu 2 b và Câu 3)
```csharp
using System.Windows;
using System.Linq;
using System.Collections.Generic;

namespace De3
{
    public partial class Window2 : Window
    {
        private MainWindow mainWindow;

        public Window2(MainWindow main)
        {
            InitializeComponent();
            this.mainWindow = main;
            // Hiển thị khác (ví dụ: toàn bộ danh sách ở Window2)
            dgWindow2.ItemsSource = main.ListKhachHang;
        }

        // Câu 3: Lọc khach hang co so tien >0, chuyen sang DataGrid cua so chinh, thong bao neu khong co
        private void btnChuyen_Click(object sender, RoutedEventArgs e)
        {
            List<KhachHang> filtered = mainWindow.ListKhachHang.Where(k => k.SoTienBanHang > 0).ToList();

            if (filtered.Count == 0)
            {
                MessageBox.Show("Khong co khach hang nao co so tien ban hang > 0!");
                return;
            }

            mainWindow.ListKhachHang.Clear();
            foreach (var item in filtered)
            {
                mainWindow.ListKhachHang.Add(item);
            }

            MessageBox.Show("Da chuyen thanh cong cac khach hang co so tien > 0 sang cua so chinh!");
        }
    }
}
```

### Hướng dẫn chạy và nộp
- Build và run project để kiểm tra.
- Sau khi xong, nén thư mục solution thành file zip với tên giống solution (ví dụ De3_412.zip).
- Lưu ý: Đề có thể có lỗi đánh máy (nhân viên/khách hàng, -10%), tôi điều chỉnh logic hợp lý. Nếu cần thêm validation hoặc template phức tạp hơn (như ControlTemplate cho button), cho biết thêm để chỉnh.

Nếu ảnh có phần bị cắt mà bạn cần bổ sung, hoặc có lỗi, hãy gửi thêm chi tiết!
