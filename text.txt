Để hiển thị danh sách phi công theo dạng bảng trong ứng dụng Console App C# trên Visual Studio 2022, chúng ta cần chỉnh sửa phương thức `DisplayPilots()` trong file `Program.cs`. Tôi sẽ sử dụng thư viện `ConsoleTable` (một cách đơn giản là tự tạo bảng bằng cách định dạng chuỗi) để hiển thị dữ liệu dưới dạng bảng. Tuy nhiên, vì ứng dụng Console không có sẵn thư viện bảng mặc định, tôi sẽ hướng dẫn cách hiển thị bảng bằng cách định dạng chuỗi thủ công để đảm bảo tương thích.

Dưới đây là mã nguồn đã được cập nhật cho cả 3 file, với thay đổi chính ở `Program.cs` để hiển thị danh sách phi công dưới dạng bảng. Tôi cũng sẽ giải thích cách thực hiện.

### File 3: Program.cs
File này được chỉnh sửa để hiển thị danh sách phi công dưới dạng bảng trong phương thức `DisplayPilots()`. Tôi sử dụng định dạng chuỗi với các ký tự viền để tạo bảng.

<xaiArtifact artifact_id="5ef5b611-7c3a-4216-9d50-ccda36138be1" artifact_version_id="15df4e52-6817-4d21-85fd-8d92b4c2205e" title="Program.cs" contentType="text/csharp">
using System;
using System.Collections.Generic;
using System.Linq;

namespace PilotManagement
{
    class Program
    {
        static List<CommercialPilot> pilots = new List<CommercialPilot>();

        static void Main(string[] args)
        {
            Console.OutputEncoding = System.Text.Encoding.UTF8; // Hỗ trợ tiếng Việt

            while (true)
            {
                Console.WriteLine("\n=== Menu Quản Lý Phi Công ===");
                Console.WriteLine("1. Thêm phi công");
                Console.WriteLine("2. Hiển thị danh sách phi công");
                Console.WriteLine("3. Sắp xếp theo kinh nghiệm giảm dần");
                Console.WriteLine("4. Thoát");
                Console.Write("Chọn chức năng (1-4): ");

                string choice = Console.ReadLine();

                switch (choice)
                {
                    case "1":
                        AddPilot();
                        break;
                    case "2":
                        DisplayPilots();
                        break;
                    case "3":
                        SortPilotsByExperience();
                        break;
                    case "4":
                        Console.WriteLine("Thoát chương trình.");
                        return;
                    default:
                        Console.WriteLine("Lựa chọn không hợp lệ. Vui lòng thử lại!");
                        break;
                }
            }
        }

        static void AddPilot()
        {
            CommercialPilot pilot = new CommercialPilot();
            pilot.Input();

            // Kiểm tra trùng số giấy phép
            if (pilots.Any(p => p.LicenseNumber == pilot.LicenseNumber))
            {
                Console.WriteLine("Số giấy phép đã tồn tại! Không thể thêm phi công này.");
                return;
            }

            pilots.Add(pilot);
            Console.WriteLine("Thêm phi công thành công!");
        }

        static void DisplayPilots()
        {
            if (pilots.Count == 0)
            {
                Console.WriteLine("Danh sách phi công trống!");
                return;
            }

            Console.WriteLine("\n=== Danh Sách Phi Công ===");

            // Định nghĩa độ rộng cột
            int colWidth = 15;
            string format = "|{0,-15}|{1,-15}|{2,-15}|{3,-15}|{4,-15}|{5,-15}|{6,-15}|";

            // Tiêu đề bảng
            Console.WriteLine(new string('-', 105));
            Console.WriteLine(format, "Họ tên", "Năm sinh", "Kinh nghiệm", "Số giấy phép", "Liên lạc", "Hãng HK", "Loại máy bay");
            Console.WriteLine(new string('-', 105));

            // Dữ liệu
            foreach (var pilot in pilots)
            {
                Console.WriteLine(format,
                    pilot.FullName.Length > 13 ? pilot.FullName.Substring(0, 13) + ".." : pilot.FullName,
                    pilot.BirthYear,
                    pilot.Experience,
                    pilot.LicenseNumber.Length > 13 ? pilot.LicenseNumber.Substring(0, 13) + ".." : pilot.LicenseNumber,
                    pilot.ContactInfo.Length > 13 ? pilot.ContactInfo.Substring(0, 13) + ".." : pilot.ContactInfo,
                    pilot.Airline.Length > 13 ? pilot.Airline.Substring(0, 13) + ".." : pilot.Airline,
                    pilot.AircraftType.Length > 13 ? pilot.AircraftType.Substring(0, 13) + ".." : pilot.AircraftType);
            }

            Console.WriteLine(new string('-', 105));
        }

        static void SortPilotsByExperience()
        {
            if (pilots.Count == 0)
            {
                Console.WriteLine("Danh sách phi công trống!");
                return;
            }

            pilots = pilots.OrderByDescending(p => p.Experience).ToList();
            Console.WriteLine("Đã sắp xếp danh sách theo kinh nghiệm giảm dần!");
            DisplayPilots();
        }
    }
}

### Giải thích thay đổi trong Program.cs
- **Phương thức `DisplayPilots()`**:
  - Tôi đã định dạng dữ liệu thành bảng bằng cách sử dụng ký tự `|` để phân chia cột và `-` để tạo đường viền.
  - Mỗi cột có độ rộng cố định là 15 ký tự (biến `colWidth`).
  - Chuỗi định dạng `format` được sử dụng để căn chỉnh dữ liệu sang trái (`{0,-15}`).
  - Nếu dữ liệu trong cột quá dài (>13 ký tự), tôi cắt ngắn và thêm `..` để tránh làm vỡ bảng (ví dụ: `pilot.FullName.Substring(0, 13) + ".."`) .
  - Tiêu đề bảng và dữ liệu được in ra theo định dạng, với các đường viền trên và dưới để dễ nhìn.

1. **Mở dự án đã tạo**:
   - Nếu bạn đã tạo dự án `PilotManagement` từ trước, chỉ cần mở lại.
   - Nếu chưa, tạo mới một Console App như hướng dẫn trước đó.

2. **Cập nhật các file**:
   - Mở file `Pilot.cs`, đảm bảo nội dung khớp với artifact đầu tiên.
   - Mở file `CommercialPilot.cs`, đảm bảo nội dung khớp với artifact thứ hai.
   - Mở file `Program.cs`, thay thế nội dung bằng artifact thứ ba.

3. **Chạy chương trình**:
   - Nhấn **F5** hoặc nút "Start".
   - Thêm một vài phi công (lựa chọn 1), sau đó chọn "Hiển thị danh sách" (lựa chọn 2) để xem kết quả dưới dạng bảng.
