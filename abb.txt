Tôi sẽ hướng dẫn bạn từng bước để thực hiện bài tập WPF này. Chúng ta sẽ tạo giao diện, áp dụng Style/Template, và viết code xử lý logic theo yêu cầu. Tôi sẽ sử dụng C# và XAML để lập trình.

### **Câu 1: Xây dựng ứng dụng WPF**

#### **a) Tạo Window có giao diện như sau:**

Chúng ta sẽ tạo một giao diện WPF với các thành phần như TextBox, DatePicker, Button, và DataGrid.

**MainWindow.xaml:**
```xaml
<Window x:Class="DoctorApp.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="THÔNG TIN BÁC SĨ" Height="450" Width="800">
    <Grid Margin="10">
        <Grid.RowDefinitions>
            <RowDefinition Height="Auto"/>
            <RowDefinition Height="Auto"/>
            <RowDefinition Height="*"/>
            <RowDefinition Height="Auto"/>
        </Grid.RowDefinitions>

        <!-- Nhập thông tin bác sĩ -->
        <StackPanel Grid.Row="0" Margin="0,0,0,10">
            <StackPanel Orientation="Horizontal" Margin="0,0,0,5">
                <Label Content="Mã:" Width="100"/>
                <TextBox x:Name="txtMa" Width="200"/>
            </StackPanel>
            <StackPanel Orientation="Horizontal" Margin="0,0,0,5">
                <Label Content="Họ tên:" Width="100"/>
                <TextBox x:Name="txtHoTen" Width="200"/>
            </StackPanel>
            <StackPanel Orientation="Horizontal" Margin="0,0,0,5">
                <Label Content="Ngày ký hợp đồng:" Width="100"/>
                <DatePicker x:Name="dpNgayKy" Width="200"/>
            </StackPanel>
            <StackPanel Orientation="Horizontal" Margin="0,0,0,5">
                <Label Content="Chuyên ngành:" Width="100"/>
                <TextBox x:Name="txtChuyenNganh" Width="200"/>
            </StackPanel>
        </StackPanel>

        <!-- DataGrid -->
        <DataGrid x:Name="dgDoctors" Grid.Row="1" AutoGenerateColumns="False" Margin="0,0,0,10">
            <DataGrid.Columns>
                <DataGridTextColumn Header="Mã" Binding="{Binding Ma}"/>
                <DataGridTextColumn Header="Họ tên" Binding="{Binding HoTen}"/>
                <DataGridTextColumn Header="Ngày ký hợp đồng" Binding="{Binding NgayKy, StringFormat=d}"/>
                <DataGridTextColumn Header="Chuyên ngành" Binding="{Binding ChuyenNganh}"/>
            </DataGrid.Columns>
        </DataGrid>

        <!-- Nút -->
        <StackPanel Grid.Row="2" Orientation="Horizontal" HorizontalAlignment="Center">
            <Button x:Name="btnMauNenBeige" Content="Màu nền Beige" Margin="5" Click="btnMauNenBeige_Click"/>
            <Button x:Name="btnDoiMauGreen" Content="Đoạn việc cơ màu Green" Margin="5" Click="btnDoiMauGreen_Click"/>
            <Button x:Name="btnNhap" Content="Nhập" Margin="5" Click="btnNhap_Click"/>
            <Button x:Name="btnThongKe" Content="Thống kê" Margin="5" Click="btnThongKe_Click"/>
        </StackPanel>
    </Grid>
</Window>
```

#### **b) Sử dụng Style, Template để định dạng:**

- **DataGrid:** Tiêu đề cột chữ đậm, căn giữa, cột "Ngày ký hợp đồng" màu xanh.
- **IsMouseOver:** Đặt màu chữ và nền thành xanh khi hover.

**Cập nhật MainWindow.xaml với Style:**
```xaml
<Window.Resources>
    <!-- Style cho DataGrid Column Header -->
    <Style TargetType="DataGridColumnHeader">
        <Setter Property="HorizontalContentAlignment" Value="Center"/>
        <Setter Property="FontWeight" Value бир: "Bold"/>
    </Style>

    <!-- Style cho cột "Ngày ký hợp đồng" -->
    <Style TargetType="DataGridCell" x:Key="NgayKyCellStyle">
        <Setter Property="Foreground" Value="Blue"/>
    </Style>

    <!-- Style cho DataGrid Row khi hover -->
    <Style TargetType="DataGridRow">
        <Style.Triggers>
            <Trigger Property="IsMouseOver" Value="True">
                <Setter Property="Background" Value="LightBlue"/>
                <Setter Property="Foreground" Value="Blue"/>
            </Trigger>
        </Style.Triggers>
    </Style>
</Window.Resources>
```

Áp dụng Style cho cột "Ngày ký hợp đồng" trong DataGrid:
```xaml
<DataGridTextColumn Header="Ngày ký hợp đồng" Binding="{Binding NgayKy, StringFormat=d}" CellStyle="{StaticResource NgayKyCellStyle}"/>
```

### **Câu 2: Viết lệnh thực hiện các yêu cầu**

#### **Code-behind (MainWindow.xaml.cs):**

Đầu tiên, tạo một lớp Doctor để lưu thông tin bác sĩ và danh sách bác sĩ:

```csharp
using System;
using System.Collections.Generic;
using System.Windows;
using System.Windows.Controls;
using System.Windows.Media;

namespace DoctorApp
{
    public partial class MainWindow : Window
    {
        private List<Doctor> doctors = new List<Doctor>();

        public MainWindow()
        {
            InitializeComponent();
        }

        // Lớp Doctor để lưu thông tin
        public class Doctor
        {
            public string Ma { get; set; }
            public string HoTen { get; set; }
            public DateTime NgayKy { get; set; }
            public string ChuyenNganh { get; set; }
        }

        // Nút "Màu nền Beige"
        private void btnMauNenBeige_Click(object sender, RoutedEventArgs e)
        {
            this.Background = new SolidColorBrush(Colors.Beige);
        }

        // Nút "Đoạn việc cơ màu Green" (Đổi màu DataGrid thành Green)
        private void btnDoiMauGreen_Click(object sender, RoutedEventArgs e)
        {
            dgDoctors.Background = new SolidColorBrush(Colors.Green);
        }

        // Nút "Nhập"
        private void btnNhap_Click(object sender, RoutedEventArgs e)
        {
            // Kiểm tra dữ liệu hợp lệ
            if (string.IsNullOrEmpty(txtMa.Text) || string.IsNullOrEmpty(txtHoTen.Text) ||
                dpNgayKy.SelectedDate == null || string.IsNullOrEmpty(txtChuyenNganh.Text))
            {
                MessageBox.Show("Vui lòng nhập đầy đủ thông tin!");
                return;
            }

            DateTime ngayKy = dpNgayKy.SelectedDate.Value;
            if (ngayKy > DateTime.Now)
            {
                MessageBox.Show("Ngày ký hợp đồng phải nhỏ hơn hoặc bằng ngày hiện tại!");
                return;
            }

            // Thêm bác sĩ vào danh sách
            doctors.Add(new Doctor
            {
                Ma = txtMa.Text,
                HoTen = txtHoTen.Text,
                NgayKy = ngayKy,
                ChuyenNganh = txtChuyenNganh.Text
            });

            // Cập nhật DataGrid
            dgDoctors.ItemsSource = null;
            dgDoctors.ItemsSource = doctors;

            // Xóa các trường nhập liệu
            txtMa.Text = "";
            txtHoTen.Text = "";
            dpNgayKy.SelectedDate = null;
            txtChuyenNganh.Text = "";
        }

        // Nút "Thống kê"
        private void btnThongKe_Click(object sender, RoutedEventArgs e)
        {
            if (dpNgayKy.SelectedDate == null)
            {
                MessageBox.Show("Vui lòng chọn ngày ký hợp đồng để thống kê!");
                return;
            }

            DateTime selectedDate = dpNgayKy.SelectedDate.Value;

            // a) Lọc bác sĩ có ngày ký hợp đồng trước ngày được chọn
            var filteredByDate = doctors.FindAll(d => d.NgayKy < selectedDate);

            // b) Lọc bác sĩ ngành "Ngoại"
            var filteredByNgoai = doctors.FindAll(d => d.ChuyenNganh.ToLower() == "ngoại");

            // Kết hợp kết quả: Lấy danh sách bác sĩ thỏa mãn cả hai điều kiện
            var result = filteredByDate.FindAll(d => filteredByNgoai.Contains(d));

            // Hiển thị kết quả lên DataGrid
            dgDoctors.ItemsSource = null;
            dgDoctors.ItemsSource = result;
        }
    }
}
```

### **Câu 3: Kiểm tra dữ liệu và xử lý ngoại lệ**

Điều này đã được thực hiện trong sự kiện `btnNhap_Click`:
- Kiểm tra tất cả các trường có dữ liệu hay không.
- Kiểm tra ngày ký hợp đồng phải nhỏ hơn hoặc bằng ngày hiện tại (hôm nay là 02/06/2025).

- **Logic:**

  - Nút "Đoạn việc cơ màu Green": Đổi màu nền DataGrid thành Green.
  - Nút "Nhập": Kiểm tra dữ liệu và thêm bác sĩ vào danh sách.
  - Nút "Thống kê": Lọc và hiển thị danh sách bác sĩ có ngày ký hợp đồng trước ngày chọn và thuộc ngành "Ngoại".
