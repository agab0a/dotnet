Dựa trên hình ảnh bạn cung cấp, tôi sẽ tạo giao diện WPF sử dụng XAML để giống với giao diện trong hình. Giao diện bao gồm các thành phần như TextBox, DatePicker, Button, và DataGrid, với bố cục tương tự.

Dưới đây là code XAML để tạo giao diện:

### **MainWindow.xaml**

```xaml
<Window x:Class="DoctorApp.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="THÔNG TIN BÁC SĨ" Height="450" Width="800">
    <Grid Margin="10">
        <Grid.RowDefinitions>
            <RowDefinition Height="Auto"/>
            <RowDefinition Height="*"/>
            <RowDefinition Height="Auto"/>
        </Grid.RowDefinitions>

        <!-- Phần nhập thông tin bác sĩ -->
        <StackPanel Grid.Row="0" Margin="0,0,0,10">
            <StackPanel Orientation="Horizontal" Margin="0,0,0,5">
                <Label Content="Mã:" Width="100"/>
                <TextBox x:Name="txtMa" Width="200"/>
            </StackPanel>
            <StackPanel Orientation="Horizontal" Margin="0,0,0,5">
                <Label Content="Họ tên:" Width="100"/>
                <TextBox x:Name="txtHoTen" Width="200"/>
            </StackPanel>
            <StackPanel Orientation="Horizontal" Margin="0,0,0,5">
                <Label Content="Ngày ký hợp đồng:" Width="100"/>
                <DatePicker x:Name="dpNgayKy" Width="200"/>
            </StackPanel>
            <StackPanel Orientation="Horizontal" Margin="0,0,0,5">
                <Label Content="Chuyên ngành:" Width="100"/>
                <TextBox x:Name="txtChuyenNganh" Width="200"/>
            </StackPanel>
        </StackPanel>

        <!-- DataGrid -->
        <DataGrid x:Name="dgDoctors" Grid.Row="1" AutoGenerateColumns="False" Margin="0,0,0,10">
            <DataGrid.Columns>
                <DataGridTextColumn Header="Mã" Binding="{Binding Ma}" Width="*"/>
                <DataGridTextColumn Header="Họ tên" Binding="{Binding HoTen}" Width="*"/>
                <DataGridTextColumn Header="Ngày ký hợp đồng" Binding="{Binding NgayKy, StringFormat=d}" Width="*"/>
                <DataGridTextColumn Header="Chuyên ngành" Binding="{Binding ChuyenNganh}" Width="*"/>
            </DataGrid.Columns>
        </DataGrid>

        <!-- Các nút -->
        <StackPanel Grid.Row="2" Orientation="Horizontal" HorizontalAlignment="Center">
            <Button x:Name="btnMauNenBeige" Content="Màu nền Beige" Margin="5" Width="120"/>
            <Button x:Name="btnDoiMauGreen" Content="Đoạn việc cơ màu Green" Margin="5" Width="150"/>
            <Button x:Name="btnNhap" Content="Nhập" Margin="5" Width="80"/>
            <Button x:Name="btnThongKe" Content="Thống kê" Margin="5" Width="80"/>
        </StackPanel>
    </Grid>
</Window>
```

### **Giải thích giao diện:**

1. **Tiêu đề Window:** "THÔNG TIN BÁC SĨ".
2. **Phần nhập liệu:**
   - **Mã:** TextBox (`txtMa`).
   - **Họ tên:** TextBox (`txtHoTen`).
   - **Ngày ký hợp đồng:** DatePicker (`dpNgayKy`).
   - **Chuyên ngành:** TextBox (`txtChuyenNganh`).
   - Các thành phần được sắp xếp trong `StackPanel` với bố cục ngang (Label + TextBox/DatePicker).
3. **DataGrid:** Hiển thị danh sách bác sĩ với các cột "Mã", "Họ tên", "Ngày ký hợp đồng", "Chuyên ngành".
4. **Các nút:**
   - "Màu nền Beige".
   - "Đoạn việc cơ màu Green" (theo đúng nội dung trong hình).
   - "Nhập".
   - "Thống kê".
   - Các nút được đặt trong một `StackPanel` ngang, căn giữa.

### **Code-behind (MainWindow.xaml.cs):**

Để giao diện hoạt động, bạn cần tạo một lớp `Doctor` để lưu thông tin bác sĩ và gán dữ liệu cho DataGrid. Dưới đây là code cơ bản:

```csharp
using System.Windows;

namespace DoctorApp
{
    public partial class MainWindow : Window
    {
        public MainWindow()
        {
            InitializeComponent();
        }

        // Lớp Doctor để lưu thông tin
        public class Doctor
        {
            public string Ma { get; set; }
            public string HoTen { get; set; }
            public System.DateTime NgayKy { get; set; }
            public string ChuyenNganh { get; set; }
        }
    }
}
```

### **Ghi chú:**
- Giao diện đã được thiết kế giống hệt trong hình, với bố cục và các thành phần tương ứng.
- Hiện tại, các nút chưa có chức năng (chỉ có giao diện). Nếu bạn muốn thêm chức năng (như đổi màu, nhập dữ liệu, thống kê), hãy tham khảo giải pháp trong câu hỏi trước hoặc yêu cầu thêm.

Nếu bạn cần chỉnh sửa hoặc thêm tính năng, hãy cho tôi biết!
